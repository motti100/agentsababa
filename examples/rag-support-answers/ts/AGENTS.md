## Run and test

- Run: `npx tsx agent.ts "your task"`
- Check setup: `npx tsx agent.ts --doctor`
- Regression suite: `npx tsx evals.ts`. Cases live in `evals.json` (export them from the AgentSababa Lab); `.github/workflows/evals.yml` runs them in CI.

## Layout

- `agent.ts`: the whole agent. Settings (MODEL, limits, SYSTEM) are at the top.
- `blueprint.json`: the design. Load it into AgentSababa to change it, then regenerate.

## Conventions

- Never commit API keys. Use environment variables (see `.env.example`).

- Change behaviour by editing SYSTEM or the tool descriptions first. Reach for new code last.
