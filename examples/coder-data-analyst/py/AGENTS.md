## Run and test

- Run: `python agent.py "your task"`
- Check setup: `python agent.py --doctor`
- Regression suite: `python evals.py`. Cases live in `evals.json` (export them from the AgentSababa Lab); `.github/workflows/evals.yml` runs them in CI.
